# Webs multiidioma — Guía de tecnologías

Cómo preparar una web para que se ofrezca en varios idiomas sin que cada idioma nuevo sea una reescritura: dónde va el idioma en la URL, cómo se declara para navegadores y buscadores, cómo se escriben los textos, las fechas y las monedas, y cómo se guardan en base de datos los contenidos traducibles.

Está pensada para perfiles backend que programan a diario pero no han tenido que traducir una web. No presupone experiencia previa en internacionalización: cada decisión se explica desde el problema que resuelve.
