# SEO web — Guía de tecnologías

Cómo hacer que un buscador pueda encontrar, entender y mostrar las páginas de una web: cómo trabaja un robot (rastreo, indexación y posicionamiento), qué errores de servidor y de HTML lo impiden, qué escribir en cada página, cómo etiquetar el contenido con datos estructurados, qué miden los Core Web Vitals y cómo comprobarlo todo en Search Console.

Está pensada para perfiles backend que programan a diario pero no han tenido que posicionar una web. No presupone experiencia previa en SEO: cada práctica se explica desde el problema que resuelve, con el fallo y su arreglo.
