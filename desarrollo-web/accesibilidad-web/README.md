# Accesibilidad web — Guía de tecnologías

Cómo comprobar y construir una web que pueda usar cualquier persona, también quien navega solo con teclado, con un lector de pantalla o con la letra ampliada. Parte del estándar internacional que lo define, WCAG, y lo baja a ejemplos de código, a un criterio para elegir nivel y versión, y a una forma práctica de comprobarlo.

Está pensada para perfiles backend que programan a diario pero no han tenido que cumplir un requisito de accesibilidad. No presupone experiencia previa: cada criterio se explica desde el problema que resuelve, con el fallo y su arreglo.
